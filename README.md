# Pet Search

A simple React app styled with Bootstrap 5 that lets you search pets by animal type or name.

## Run it

```
npm install
npm run dev
```

## Files

- `src/data.js` – pet data (id, name, animal, specialty, image)
- `src/components/PetList.jsx` – search box and table of pets
- `src/App.jsx` – filters the pets by animal or name (upper or lower case)
- `public/images/` – pet pictures and the background
